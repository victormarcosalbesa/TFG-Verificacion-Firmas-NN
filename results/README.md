# Resultados

Esta carpeta contiene los resultados obtenidos durante el entrenamiento y la evaluación de los modelos desarrollados en el TFG.

Los resultados incluyen gráficas comparativas, métricas de rendimiento y una tabla resumen con los valores obtenidos por los distintos modelos entrenados.

## Contenido de la carpeta

En esta carpeta se incluyen cuatro archivos principales:

| Archivo                | Descripción                                                         |
| ---------------------- | ------------------------------------------------------------------- |
| `comparativa_barras.png`        | Gráfica comparativa de las diferentes métricas utilizadas para cada modelo.         |
| `comparativa_global.png`        | Gráfica comparativa de error de entrenamiento y validación entre los distintos modelos de MLP y CNN.         |
| `comparativa_subplots.png`        | Gráfica comparativa entre el error de entrenamiento y validación para cada modelo.         |
| `comparativa biometrica.csv` | Tabla resumen con las métricas y las matrices de confusión obtenidas por los modelos evaluados. |

## Descripción

Las gráficas permiten visualizar el comportamiento de los modelos durante el entrenamiento y la evaluación, facilitando la comparación entre las arquitecturas implementadas, principalmente CNN y MLP.

La tabla de resultados recoge las métricas principales utilizadas para analizar el rendimiento de cada modelo, como la precisión, la pérdida y otras métricas relevantes para la clasificación de imágenes, así como las matrices de confusión.
