# Resultados

Esta carpeta contiene los resultados obtenidos durante el entrenamiento y la evaluación de los modelos desarrollados en el TFG.

Los resultados incluyen gráficas comparativas, métricas de rendimiento y una tabla resumen con los valores obtenidos por los distintos modelos entrenados.

## Contenido de la carpeta

En esta carpeta se incluyen cinco archivos principales:

| Archivo                | Descripción                                                         |
| ---------------------- | ------------------------------------------------------------------- |
| `grafica_1.png`        | Primera gráfica generada durante el análisis de resultados.         |
| `grafica_2.png`        | Segunda gráfica generada durante el análisis de resultados.         |
| `grafica_3.png`        | Tercera gráfica generada durante el análisis de resultados.         |
| `grafica_4.png`        | Cuarta gráfica generada durante el análisis de resultados.          |
| `tabla_resultados.csv` | Tabla resumen con las métricas obtenidas por los modelos evaluados. |

## Descripción

Las gráficas permiten visualizar el comportamiento de los modelos durante el entrenamiento y la evaluación, facilitando la comparación entre las arquitecturas implementadas, principalmente CNN y MLP.

La tabla de resultados recoge las métricas principales utilizadas para analizar el rendimiento de cada modelo, como la precisión, la pérdida y otras métricas relevantes para la clasificación de imágenes.

## Uso

Estos resultados sirven como apoyo visual y cuantitativo para justificar la elección del modelo final utilizado en la aplicación móvil.

## Nota

Los nombres de los archivos pueden modificarse para adaptarse a los nombres reales de las gráficas y de la tabla utilizadas en el proyecto.
